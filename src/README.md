# 🚀 Finecore360

An Employee Management System built using Java, Spring Boot, Thymeleaf, MySQL, HTML, CSS, and Bootstrap.

## 📌 Project Overview

Finecore360 is a Java Full Stack project developed to manage employee records efficiently. It provides features like adding, updating, deleting, searching, filtering, and sorting employee data through a user-friendly web interface.

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Thymeleaf
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- Maven
- Git
- GitHub

## ✨ Features

- Add Employee
- Update Employee
- Delete Employee
- Employee Validation
- Search Employee by Name
- Filter by Department
- Sort Employees (A-Z / Z-A)
- Dashboard with Statistics
- Dynamic Department Dropdown
- Employee ID starts from 1001
- Responsive User Interface

## ▶️ How to Run the Project

1. Clone the repository
2. Open the project in VS Code or IntelliJ IDEA
3. Configure MySQL Database
4. Update `application.properties`
5. Run the Spring Boot application
6. Open your browser and visit:
   ```
   http://localhost:8080/
   ```
